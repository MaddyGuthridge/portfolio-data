# Nyx

<score lang="ABC">
X: 1
M: 2/2
L: 1/4
K: Gmin
G d c d | f d c d | G4- | G4 |]

The Greek goddess of night, born of Chaos (the void), mother to darkness, death and sleep.

This was my first ever published Black MIDI. I'm immensely proud of the work I did on it.
